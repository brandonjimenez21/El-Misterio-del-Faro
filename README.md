# El Misterio del Faro

Demo de terror y misterio en Unity (URP), ambientada en el siglo XIX: despiertas en un faro solitario de una isla remota durante una tormenta y debes resolver tres puzles para llegar a la lámpara.

## Contenido

- `puzzles_objetos.txt`: idea del juego, puzles y lista de objetos.
- `blender/el_misterio_del_faro.blend`: modelos 3D de los puzles (candado, postes de navegación, caldera de vapor, muelle, reloj de luna, luna, etc.), con aspecto antiguo y desgastado.
- `blender/island.blend`: modelos 3D de la isla con diferentes pesos en poligonos.
- `Assets/Models/Faro/`: FBX exportados desde Blender y texturas horneadas (color, relieve y metal/brillo).
- `Assets/Materials/Faro/`: materiales URP de cada objeto.
- Imágenes de referencia: `aspecto_estetica_terror.jpg`, `isla_modelo.jpg`, `mapa_ubicaciones.jpg`.

La isla no está incluida en este repositorio.
